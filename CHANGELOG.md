# Changelog

All notable changes to EgoFlow Server are documented in this file.

## [0.0.1] - 2026-08-12

### Added

- Self-hosted backend and web dashboard for managing EgoFlow recordings.
- Authenticated RTMP, RTMPS, WHIP, and HTTP ingestion workflows.
- Dataset manifest, video download, thumbnail, live-stream, and Python token APIs.
- Recording processing backed by PostgreSQL and Redis.
